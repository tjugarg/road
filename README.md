# Road Safety Survey

A mobile web prototype for road condition verification, built for user testing.

## Setup

```bash
npm install
```

## Local Development

```bash
npm run dev
```

Opens at `http://localhost:5173`

## Deploy to GitHub Pages

```bash
npm run deploy
```

Your site will be live at `https://YOUR_USERNAME.github.io/road-safety-survey/`

## Important

If you name your GitHub repo something other than `road-safety-survey`, update the `base` path in `vite.config.js` to match:

```js
base: '/your-repo-name/',
```
